3:T840,## Overview

DonutHomes gives every player numbered homes managed through a native dialog. Players set a home on a free slot, rename it, give it an icon, teleport to it or delete it. How many slots a player can use depends on permissions.

### Requirements

* Paper or Folia 1.21.6 or newer, since the menus use native dialogs

### Installation

1. Put `DonutHomes.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `licenseKey` in the main config. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/home` | Open the homes dialog (alias `/homes`) | `donuthomes.homes.use` |
| `/sethome <number>` | Set a home on that slot | `donuthomes.homes.use` |
| `/delhome <number>` | Delete the home on that slot | `donuthomes.homes.use` |

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `donuthomes.homes.use` | Open and use homes | everyone |
| `donuthomes.homes.slots.<n>` | Unlock home slots up to number `n` | none |
| `donuthomes.homes.slots.*` | Unlock every slot | op |

Players get `defaultUnlockedHomes` slots without a permission. The highest `slots.<n>` permission a player has decides how many more they can use.

## Configuration

| Option | Default | Description |
| --- | --- | --- |
| `maxHomes` | `90` | Slots shown in the dialog |
| `defaultUnlockedHomes` | `2` | Slots every player has |
| `slotPermission` | `donuthomes.homes.slots.{slot}` | Permission pattern per slot |
| `allSlotsPermission` | `donuthomes.homes.slots.*` | Permission for every slot |
| `defaultHomeName` | `Home {slot}` | Name of a new home |
| `defaultIcon` | `WHITE_BED` | Icon of a new home |
| `database.type` | `SQLITE` | `SQLITE` or `MYSQL` |

The main dialog (title, columns, button size, labels and tooltips), the manage dialog (rename input, buttons), the icon picker and all messages are configurable with `&` color codes.

## Support
