3:Tad4,## Overview

DonutCore bundles the systems of a DonutSMP style server in one plugin. Every system is a module that you switch on or off under `Modules:` in `config.yml`.

### Requirements

* Paper or Folia 1.21 or newer
* FancyHolograms and Vault
* Optional: PlaceholderAPI, WorldGuard, EssentialsX, CrateReloaded, ShopGUIPlus, Multiverse-Core, SkinsRestorer, Shards

### Installation

1. Put `DonutCore.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license-key` in `plugins/DonutCore/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description |
| --- | --- |
| `/balance`, `/bal`, `/money` | Show a balance |
| `/pay` | Send money to a player |
| `/baltop`, `/balancetop` | Richest players |
| `/shop` | Open the shop |
| `/sell`, `/sellhistory`, `/sellmulti`, `/worth` | Sell items, your sell history, sell multipliers and item prices |
| `/home`, `/homes`, `/sethome`, `/delhome` | Homes |
| `/tpa`, `/tpahere`, `/tpaccept`, `/tpadeny`, `/tpacancel` | Teleport requests |
| `/tpatoggle`, `/tpaheretoggle`, `/tpauto` | Request preferences |
| `/warp`, `/setwarp`, `/deletewarp` | Warps |
| `/rtp` (aliases `/randomtp`, `/wildtp`, `/wild`) | Random teleport |
| `/team` | Teams |
| `/crate` (aliases `/crates`, `/donutcrate`, `/donutcrates`) | Manage crates and keys |
| `/enderchest`, `/ec` | Enderchest |
| `/fly` | Toggle flight |
| `/phantom` | Disable or enable phantoms |
| `/stats`, `/statsmanager` | Player stats and the admin tool for them |
| `/leaderboard` | Leaderboards |
| `/itemcontrol` (aliases `/ic`, `/itemban`) | `check`, `clear` or `info` for item control |
| `/spawner`, `/mythictools`, `/billford`, `/billfordpreset` | Spawners, special tools and the BillFord module |
| `/settings` | Player settings menu |
| `/setmainspawn`, `/build` | Spawn and build mode |
| `/combatmanager` | Combat tag management |
| `/donutcore` | Plugin admin command |

## Configuration

### config.yml

`license-key` holds your key. `Modules.<name>.enabled` switches a module on or off. Modules include crates, double jump, phantom, warp, rtp, rtp zone, clearlag, shop, sell and more. Disabled by default: double jump, phantom and clearlag.

Each module keeps its settings in its own folder in `plugins/DonutCore/`: `Core`, `Economy`, `Shop`, `Sell`, `Home`, `Teleport`, `Team`, `Warps`, `Rtp`, `RtpZone`, `Crates`, `Combat`, `Fly`, `Kills`, `Stats`, `Spawn`, `Spawner`, `Settings`, `ItemControl`, `CustomEnderChest`, `DoubleJump`, `Phantoms`, `PlayerTracker`, `Portals`, `ClearLag`, `MythicTools`, `BillFord` and `leaderboard3`.
