3:Te4e,## Overview

Performance keeps a busy SMP running smoothly. It limits entities per player, chunk and world, trims overcrowded farms, stacks and cleans up dropped items, slows down mob AI far from players and steps in with an anti-lag system when TPS drops. Every feature is a module you switch on or off in `config.yml`.

### Requirements

* Paper or Folia 1.21 or newer

### Installation

1. Put `DonutPerformance.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license-key` in `plugins/DonutPerformance/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/donutperf` | TPS, MSPT, chunk scanner and every active feature (aliases `/dperf`, `/dperformance`) | `donutperf.use` |
| `/donutperf reload` | Reload the config | `donutperf.reload` |
| `/entityclear gui` | Menu that counts every entity type and clears a category with a click (aliases `/eclear`, `/dpclear`) | `donutperf.clear` |
| `/entityclear <all\|category>` | Clear entities from the command line | `donutperf.clear` |
| `/farm [top\|inspect\|stats\|reload]` | Farm detection and inspection | `donutperf.farm` |
| `/player [stats\|afk\|rankings\|recommendations] <player>` | Player performance and AFK analytics | `donutperf.player` |
| `/antilag [status\|reload]` | Anti-lag status | `donutperf.antilag` |

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `donutperf.use` | Use `/donutperf` | op |
| `donutperf.reload` | Reload the config | op |
| `donutperf.notify` | Receive overcrowding and performance alerts | op |
| `donutperf.clear` | Use `/entityclear` | op |
| `donutperf.farm` | Use `/farm` | op |
| `donutperf.player` | Use `/player` | op |
| `donutperf.antilag` | Use `/antilag` | op |

## Features

* **Overcrowding protection:** pens with too many animals are trimmed, with an alert for staff.
* **Entity limits:** per player, per chunk and per world caps, breeding limits and villager limits.
* **Mob AI throttling and activation range:** mobs far from players use less server time.
* **Item optimizer:** item stacking, faster despawn, density limits and rare item protection.
* **Anti-lag in 8 stages:** when TPS drops it steps in stage by stage, from entity caps to view distance.
* **Entity clear menu and scheduled auto clear.**
* **AFK optimization:** AFK players cost less, with alerts and analytics.

## Configuration

`config.yml` turns each module on or off:

| Section | Modules |
| --- | --- |
| `entitylimiter` | `playerlimit`, `chunklimit`, `worldlimit`, `dynamiccaps`, `breeding`, `mobai`, `activationrange`, `freezing`, `villageropt`, `overcrowding`, `clear`, `autoclear` |
| `itemoptimizer` | `stacking`, `despawn`, `rareprotection`, `density`, `cleanup`, `emergency`, `analytics` |
| `farmoptimizer` | `scanner`, `controller`, `cropthrottle`, `villagerlimit` |
| `antilag` | `controller` |
| `playeroptimizer` | `afk`, `afkopt`, `alerts` |

| Option | Default | Description |
| --- | --- | --- |
| `license-key` | | Your license key |
| `observe-mode` | `false` | Measure and report only, without acting |
| `scanner.interval-ticks` | `60` | Ticks between chunk scans |
| `scanner.chunks-per-tick` | `150` | Chunks scanned per tick |
| `scanner.folia-radius-chunks` | `4` | Scan radius around players on Folia |

Each module has its own file under `features/<section>/<module>/config.yml` with its limits and thresholds. Messages are in `messages.yml`.
