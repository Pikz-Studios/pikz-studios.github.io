3:Tb17,## Overview

Friends gives every player a friends list built on following. A player follows someone by name, and when that player follows back they become friends. `/friends` opens a dialog with friends, followers and who you follow, with a dot that shows who is online. `/msg` sends private messages.

### Requirements

* Paper or Folia 1.21.6 or newer, since the menus use native dialogs

### Installation

1. Put `DonutFriends.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license-key` in `plugins/DonutFriends/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/friends` | Open the friends dialog (aliases `/friend`, `/fl`) | `donutfriends.use` |
| `/friends add <player>` | Follow a player | `donutfriends.use` |
| `/friends remove <player>` | Unfollow a player | `donutfriends.use` |
| `/friends list` | List your friends in chat | `donutfriends.use` |
| `/msg <player> <message>` | Send a private message (aliases `/tell`, `/w`, `/pm`) | `donutfriends.msg` |

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `donutfriends.use` | Use `/friends` and the friends dialog | everyone |
| `donutfriends.msg` | Send private messages | everyone |

## Features

* **Friends dialog:** friends, followers and following in one list, online players marked green.
* **Filter:** switch between All, Friends, Following and Followers.
* **Search:** type a name into the search dialog to jump to that player.
* **Follow:** follow anyone by name. They get a message that you started following them (`notify-on-follow`).
* **Mutual friends:** follow each other and you become friends, with a message for both players.
* **Private messages:** `/msg` or the message button in the dialog. Each player decides which friends can message them.

## Configuration

`config.yml`

| Option | Default | Description |
| --- | --- | --- |
| `license-key` | | Your license key |
| `friends-cache-seconds` | `30` | How long friend lists stay cached |
| `friends-cache-maximum-size` | `10000` | Maximum cached friend lists |

`database.yml`

| Option | Default | Description |
| --- | --- | --- |
| `type` | `SQLITE` | `SQLITE` or `MYSQL` |
| `sqlite.file` | `data.db` | SQLite file name |
| `mysql.host` | `localhost` | MySQL host |
| `mysql.port` | `3306` | MySQL port |
| `mysql.database` | `donutfriends` | MySQL database name |
| `pool.maximum-pool-size` | `10` | Connection pool size |

`features/friends.yml` holds the command aliases, every dialog title, button, label and color, the online and offline markers, and the private message formats.
