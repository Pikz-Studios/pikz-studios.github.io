ZelBounty

v3.0.2

Player bounties with dialog menus and durable storage.

Open

Overview

ZelBounty lets players put money on each other's heads. Anyone can raise a bounty through a menu or a command, and the player who kills the target collects it. Amounts accept short forms like 100k, 1.5m and 250000.

Requirements

  • Paper or Folia 1.21.11 or newer
  • Vault and a Vault-compatible economy plugin
  • Optional: PlaceholderAPI, Floodgate, Geyser, ViaVersion

Installation

  1. Put ZelBounty.jar in your plugins folder.
  2. Start the server once so the config files are created.
  3. Set license-key in plugins/ZelBounty/config.yml. Get your key on discord.gg/pikzstudios.
  4. Restart the server.

Commands

CommandDescriptionPermission
/bountyOpen the bounty board (aliases /bounties, /zbounty, /zelbounty)zelbounty.use
/bounty place [player] [amount]Place or raise a bounty (aliases add, set)zelbounty.place
/bounty check [player]Look up a bounty (alias info)zelbounty.use
/bounty toggleToggle bounty announcements for yourself (alias announcements)zelbounty.toggle
/bountytoggleSame as /bounty togglezelbounty.toggle
/bounty helpShow the help messagezelbounty.use

Without a player, /bounty place opens a player picker. With a player but no amount it opens an amount prompt.

Admin commands

CommandDescription
/bounty admin add <player> <amount>Add a free bounty
/bounty admin remove <player> <amount>Remove part of a bounty
/bounty admin reset <player>Clear a bounty
/bounty reloadReload all config files

The console can also run add, remove and reset directly.

Money formatting

The formatting.money section controls how amounts look. With compact mode on, large values show as K, M, B and T.

formatting:
  money:
    pattern: '#,##0.##'
    prefix: $
    compact:
      enabled: true
      thousand: K
      million: M
      billion: B
      trillion: T

Database

database.yml selects SQLite or MySQL storage. shared-cache-refresh-seconds in config.yml controls how often several servers on one database refresh each other.

Menus and sounds

The bounty board is gui/board.yml. The player picker and amount prompt are in gui/dialogs/. Sounds are set in sounds.yml. All messages and lore live in config.yml.
