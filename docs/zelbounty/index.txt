17:T1309,## Overview

ZelBounty lets players put money on each other's heads. Anyone can raise a bounty through a menu or a command, and the player who kills the target collects it. Amounts accept short forms like `100k`, `1.5m` and `250000`.

### Requirements

* Paper or Folia 1.21.11 or newer
* Vault and a Vault-compatible economy plugin
* Optional: PlaceholderAPI, Floodgate, Geyser, ViaVersion

### Installation

1. Put `ZelBounty.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license-key` in `plugins/ZelBounty/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/bounty` | Open the bounty board (aliases `/bounties`, `/zbounty`, `/zelbounty`) | `zelbounty.use` |
| `/bounty place [player] [amount]` | Place or raise a bounty (aliases `add`, `set`) | `zelbounty.place` |
| `/bounty check [player]` | Look up a bounty (alias `info`) | `zelbounty.use` |
| `/bounty toggle` | Toggle bounty announcements for yourself (alias `announcements`) | `zelbounty.toggle` |
| `/bountytoggle` | Same as `/bounty toggle` | `zelbounty.toggle` |
| `/bounty help` | Show the help message | `zelbounty.use` |

Without a player, `/bounty place` opens a player picker. With a player but no amount it opens an amount prompt.

### Admin commands

| Command | Description |
| --- | --- |
| `/bounty admin add <player> <amount>` | Add a free bounty |
| `/bounty admin remove <player> <amount>` | Remove part of a bounty |
| `/bounty admin reset <player>` | Clear a bounty |
| `/bounty reload` | Reload all config files |

The console can also run `add`, `remove` and `reset` directly.

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `zelbounty.use` | Open the board and look up bounties | everyone |
| `zelbounty.place` | Place and raise bounties | everyone |
| `zelbounty.claim` | Collect bounties on kill | everyone |
| `zelbounty.toggle` | Toggle announcements | everyone |
| `zelbounty.bypass-cooldown` | Skip the add cooldown | op |
| `zelbounty.admin` | Admin commands | op |

Node names can be changed under `permissions:` in `config.yml`.

## Configuration

### config.yml

| Option | Default | Description |
| --- | --- | --- |
| `prefix` | `&#FF0000&lBOUNTY &7▷ ` | Message prefix |
| `bounty.minimum-addable` | `1000` | Smallest amount a player can add |
| `bounty.maximum-addable` | `0` | Largest amount a player can add, `0` is unlimited |
| `bounty.add-cooldown.enabled` | `true` | Cooldown between additions |
| `bounty.add-cooldown.duration-seconds` | `5` | Length of the cooldown |
| `allow-bounty-on-self` | `false` | Allow players to bounty themselves |
| `enable-money-decimals` | `false` | Allow decimal amounts |
| `confirm-place` | `true` | Ask before placing |
| `bounty-announce` | `true` | Announce new bounties |
| `bounty-claim-announce` | `true` | Announce claimed bounties |
| `announce.place-minimum` | `100000` | Smallest bounty that is announced |
| `announce.claim-minimum` | `100000` | Smallest claim that is announced |
| `blacklisted-worlds.enabled` | `false` | Disable bounties in listed worlds |
| `blacklisted-worlds.worlds` | `world_nether`, `world_the_end` | Worlds where bounties do not work |
| `dialogs.mode` | `DIALOG` | `DIALOG` for native dialogs, or chat prompts |
| `dialogs.chat-timeout-seconds` | `60` | Time to answer a chat prompt |
| `dialogs.bedrock-prefix` | `.` | Prefix of Bedrock player names |

### Money formatting

The `formatting.money` section controls how amounts look. With compact mode on, large values show as `K`, `M`, `B` and `T`.

```yaml
formatting:
  money:
    pattern: '#,##0.##'
    prefix: $
    compact:
      enabled: true
      thousand: K
      million: M
      billion: B
      trillion: T
```

### Database

`database.yml` selects SQLite or MySQL storage. `shared-cache-refresh-seconds` in `config.yml` controls how often several servers on one database refresh each other.

### Menus and sounds

The bounty board is `gui/board.yml`. The player picker and amount prompt are in `gui/dialogs/`. Sounds are set in `sounds.yml`. All messages and lore live in `config.yml`.

## Placeholders

Requires PlaceholderAPI. The identifier is `zelbounty`.

| Placeholder | Description |
| --- | --- |
| `%zelbounty_bounty%` | Bounty on the player, formatted |
| `%zelbounty_bounty_raw%` | Bounty on the player, plain number |
| `%zelbounty_count%` | Active bounties on the server |
| `%zelbounty_top_<n>_name%` | Name of the nth highest bounty |
| `%zelbounty_top_<n>_amount%` | Amount of the nth highest bounty, formatted |
| `%zelbounty_top_<n>_amount_raw%` | Amount of the nth highest bounty, plain number |
