17:T3d4b,## Overview

Essentials Staff & Moderation (plugin name EconomyEssentials) is a staff and admin toolkit. It covers punishments with history and alt detection, staff mode, vanish and freeze, inventory tools, chat control, anti spam, anti bot and anti VPN protection, scheduled restarts and a lot of small staff commands. Every feature can be switched off on its own.

### Requirements

* Paper or Folia 1.21 or newer
* Optional: LuckPerms, Simple Voice Chat (voice mute commands)

### Installation

1. Put `EconomyEssentials.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license-key` in `plugins/EconomyEssentials/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

## Configuration

### Feature toggles

`config.yml` has one switch per feature under `features:`. Set a feature to `false` to disable it and its commands. `config-reload-check-ms` controls how often file changes are picked up.

Every feature keeps its own `config.yml` and `messages.yml` in `plugins/EconomyEssentials/features/<feature>/`.

### Punishments

| Option | Default | Description |
| --- | --- | --- |
| `database.type` | `sqlite` | `sqlite` or `mysql` |
| `notify-staff` | `true` | Tell staff about punishments |
| `prevent-double` | `true` | Block punishing a player twice |
| `undo-window-seconds` | `300` | Time `/undolast` stays available |
| `altban-reason` | `Ban-Evasion` | Reason used by `/altban` |
| `public-broadcast.enabled` | `false` | Announce selected actions publicly |
| `webhook.enabled` | `false` | Send punishments to a Discord webhook |

### Anti spam

| Option | Default | Description |
| --- | --- | --- |
| `chat-cooldown-seconds` | `2` | Time between chat messages |
| `command-cooldown-seconds` | `0` | Time between commands |
| `block-duplicates` | `true` | Block repeated messages |
| `duplicate-window-seconds` | `30` | Window for the duplicate check |
| `caps.max-percent` | `70` | Highest share of capital letters |
| `unicode.max-percent` | `40` | Highest share of unicode characters |
| `alert-staff` | `false` | Alert staff on blocked messages |

### Anti bot

| Option | Default | Description |
| --- | --- | --- |
| `window-seconds` | `10` | Window for counting joins |
| `max-joins` | `8` | Joins in the window that start an attack |
| `attack-seconds` | `60` | How long attack mode lasts |
| `rejoin-cooldown-ms` | `1500` | Minimum time before a player can rejoin |

### Anti VPN

| Option | Default | Description |
| --- | --- | --- |
| `action` | `block` | What happens to a VPN or proxy join |
| `api-url` | ip-api.com | Lookup service, `%ip%` is replaced |
| `cache-minutes` | `60` | How long results are remembered |
| `block-on-api-error` | `false` | Block when the lookup fails |
| `bypass-players` | `[]` | Players that are never checked |

### IP limit

`max-per-ip` (default `2`) sets how many accounts can join from one IP. `economyessentials.iplimit.bypass` skips it.

### Auto restart

`times` lists daily restart times such as `"04:00"`. `warnings` lists the seconds before the restart to warn at, `commands-before` runs commands such as `save-all`, and `kick-screen` is shown to players that are kicked for the restart.

### Maintenance

`/maintenance on` kicks everyone without `economyessentials.maintenance.bypass`. The `motd` and `kick-screen` lines in the maintenance config set what players see.
