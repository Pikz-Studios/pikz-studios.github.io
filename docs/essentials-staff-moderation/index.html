Essentials Staff & Moderation

v1.0.0

Staff tools, punishments and server protection in one plugin.

Open

Overview

Essentials Staff & Moderation (plugin name EconomyEssentials) is a staff and admin toolkit. It covers punishments with history and alt detection, staff mode, vanish and freeze, inventory tools, chat control, anti spam, anti bot and anti VPN protection, scheduled restarts and a lot of small staff commands. Every feature can be switched off on its own.

Requirements

  • Paper or Folia 1.21 or newer
  • Optional: LuckPerms, Simple Voice Chat (voice mute commands)

Installation

  1. Put EconomyEssentials.jar in your plugins folder.
  2. Start the server once so the config files are created.
  3. Set license-key in plugins/EconomyEssentials/config.yml. Get your key on discord.gg/pikzstudios.
  4. Restart the server.

Configuration

Feature toggles

config.yml has one switch per feature under features:. Set a feature to false to disable it and its commands. config-reload-check-ms controls how often file changes are picked up.

Every feature keeps its own config.yml and messages.yml in plugins/EconomyEssentials/features/<feature>/.

IP limit

max-per-ip (default 2) sets how many accounts can join from one IP. economyessentials.iplimit.bypass skips it.

Auto restart

times lists daily restart times such as "04:00". warnings lists the seconds before the restart to warn at, commands-before runs commands such as save-all, and kick-screen is shown to players that are kicked for the restart.

Maintenance

/maintenance on kicks everyone without economyessentials.maintenance.bypass. The motd and kick-screen lines in the maintenance config set what players see.
