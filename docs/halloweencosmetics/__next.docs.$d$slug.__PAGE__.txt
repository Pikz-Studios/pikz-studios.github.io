3:T6ee,## Overview

HalloweenCosmetics adds a set of Halloween items: a suit, sword, elytra, crystal and more. Each one has its own particle effect and sound, and staff change the particles in an editor menu.

### Requirements

* Paper or Folia 1.21 or newer

### Installation

1. Put `HalloweenCosmetics.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `License-Key` in `plugins/HalloweenCosmetics/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/hc give <player> <cosmetic>` | Give a cosmetic to a player | `halloweencosmetics.admin` |
| `/hc help` | Show the help message | `halloweencosmetics.admin` |
| `/cosmeticseditor` | Open the cosmetics editor menu | `halloweencosmetics.admin` |

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `halloweencosmetics.admin` | Give cosmetics and use the editor | op |

## Configuration

`config.yml` has a `cosmetics:` section with `SUIT`, `SWORD`, `ELYTRA` and `CRYSTAL`. Each cosmetic sets:

| Option | Description |
| --- | --- |
| `material` | The item |
| `name` and `lore` | Display name and description |
| `enchants` | Enchantments on the item |
| `defaultParticles` | Particles the cosmetic starts with |
| `sound` | Sound played with the effect |
| `soundDelayMs` | Time between sounds |
| `particleForwardDistance` | How far in front of the player the effect appears (sword) |

The `gui` section sets the editor titles and messages. In the editor you add or remove particles per cosmetic and the change is saved.

## Support
