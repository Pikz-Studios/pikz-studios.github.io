3:T12f8,## Overview

Gens lets players place generator blocks that produce items on a timer. Generators upgrade through tiers, show a live hologram with the next drop, can be boosted, and everything they make is sold through a sell menu or a sell wand.

### Requirements

* Paper or Folia 1.20 or newer
* Optional: Vault for money, DecentHolograms for the hologram, PlaceholderAPI

### Installation

1. Put `Gens.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license-key` in `plugins/Gens/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/gens` | Open the generators menu (aliases `/gen`, `/generators`) | `gens.use` |
| `/gens shop` | Open the generator shop | `gens.shop` |
| `/gens stats` | View your stats | `gens.use` |
| `/gens list` | List your placed generators | `gens.use` |
| `/gens help` | Show the help message | `gens.use` |
| `/sell` | Open the sell menu (aliases `/sellmenu`, `/sm`) | `gens.sell` |

### Admin commands

All of these need `gens.admin`. The base command is `/gensadmin` (aliases `/ga`, `/genadmin`) and opens the admin menu on its own.

| Command | Description |
| --- | --- |
| `/gensadmin give <player> <type> [tier]` | Give a generator |
| `/gensadmin sellwand give <player> [uses]` | Give a sell wand |
| `/gensadmin booster <player\|global> <type\|all> <multiplier> <duration_seconds>` | Start a booster |
| `/gensadmin info <player>` | Show a player's generators |
| `/gensadmin list` | List every placed generator |
| `/gensadmin remove <player>` | Remove a player's generator |
| `/gensadmin removeall <player>` | Remove all of a player's generators |
| `/gensadmin reload` | Reload all config files |

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `gens.use` | Use `/gens` | everyone |
| `gens.place` | Place generators | everyone |
| `gens.break` | Break generators | everyone |
| `gens.upgrade` | Upgrade generators | everyone |
| `gens.sell` | Use the sell menu | everyone |
| `gens.shop` | Use the shop | everyone |
| `gens.sellwand.use` | Use a sell wand | everyone |
| `gens.sellwand.give` | Give sell wands | op |
| `gens.booster.use` | Use boosters | everyone |
| `gens.admin` | Admin commands | op |

### Generator types

Each type has its own permission. `wood`, `stone`, `coal`, `iron`, `lapis`, `redstone` and `gold` default to everyone. `diamond`, `emerald` and `netherite` default to op.

| Permission | Type |
| --- | --- |
| `gens.type.wood` | Wood |
| `gens.type.stone` | Stone |
| `gens.type.coal` | Coal |
| `gens.type.iron` | Iron |
| `gens.type.lapis` | Lapis |
| `gens.type.redstone` | Redstone |
| `gens.type.gold` | Gold |
| `gens.type.diamond` | Diamond |
| `gens.type.emerald` | Emerald |
| `gens.type.netherite` | Netherite |

## Configuration

### config.yml

| Option | Default | Description |
| --- | --- | --- |
| `database.type` | `SQLITE` | `SQLITE` or MySQL settings below it |
| `settings.max-gens-per-player` | `10` | Generators one player can place |
| `settings.holograms-enabled` | `true` | Show holograms above generators |
| `settings.hologram-update-interval` | `20` | Hologram refresh in ticks |
| `settings.hologram-height-offset` | `0.3` | Hologram height above the block |
| `settings.production-drop-naturally` | `false` | Drop items in the world |
| `settings.allow-break-others-gen` | `false` | Let players break other players' generators |
| `settings.direct-to-inventory` | `false` | Send production straight to the inventory |
| `sell-wand.enabled` | `true` | Enable the sell wand |
| `sell-wand.material` | `BLAZE_ROD` | Item used for the wand |
| `sell-wand.default-uses` | `100` | Uses of a new wand |

The hologram lines use `{name}`, `{tier}`, `{amount}`, `{item}`, `{interval}`, `{sell_price}` and `{countdown}`.

### Generators

`generators.yml` defines each type and its tiers. A type has a `name`, `permission` and `block-material`. Every tier sets the upgrade `cost`, the `production-item`, `production-amount`, `production-interval` in seconds, the `sell-price` and the menu `icon` and `lore`.

```yaml
generators:
  wood:
    name: "&eWood Generator"
    permission: "gens.type.wood"
    block-material: "OAK_LOG"
    tiers:
      1:
        cost: 0.0
        production-item: "OAK_LOG"
        production-amount: 1
        production-interval: 30
        sell-price: 2.0
```

### Menus

Each menu has its own file: `gens-inventory.yml`, `shop-inventory.yml`, `sell-inventory.yml`, `upgrade-inventory.yml`, `booster-inventory.yml`, `stats-inventory.yml` and `admin-inventory.yml`. Messages are in `messages.yml` and sounds in `sounds.yml`.
