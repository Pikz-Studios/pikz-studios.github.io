ZelAuction

v2.0.3

Customizable auctions with dialog search and durable storage.

Open

Overview

ZelAuction is an auction house for Paper and Folia servers. Players list items for a price, browse and search listings, buy with Vault money and collect expired or returned items from a mailbox. Search and sell prompts use native dialogs, with a chat fallback for Bedrock players.

Requirements

  • Paper or Folia 1.21.11 or newer
  • Vault and a Vault-compatible economy plugin
  • Optional: PlaceholderAPI, Floodgate, Geyser, ViaVersion

Installation

  1. Put ZelAuction.jar in your plugins folder.
  2. Start the server once so the config files are created.
  3. Set license-key in plugins/ZelAuction/config.yml. Get your key on discord.gg/pikzstudios.
  4. Restart the server.

Admin commands

CommandDescription
/ah-admin reloadReload all config files
/ah-admin lockToggle the auction house lock
/ah-admin debugShow listing, parcel, recovery and payout counts
/ah-admin recovery <operation-uuid> <complete|cancel|refund>Resolve an interrupted transfer
/ah-admin force-sell <player> <price> [amount]Force a listing for a player

reload, lock, debug, recovery and force-sell also work as /ah <subcommand> for staff with zelauction.admin.

Listing limits

Max-Item-Permissions in config.yml sets how many listings a player can hold at once. The highest matching permission wins, max-listings is the fallback.

max-listings: 5
Max-Item-Permissions:
  - ah.default:5
  - ah.canyon:10
  - ah.canyon+:15
  - ah.canyon++:25

Every permission node can be renamed under permissions: in config.yml. All messages, words, sort labels, categories and item lore live in the same file, with & codes and &#RRGGBB hex colors.

Database

database.yml selects the storage backend.

Database-Type: SQLite
MySQL:
  host: localhost
  port: 3306
  database: zelauction
  user: root
  password: ''
Redis:
  enabled: false
  host: localhost
  port: 6379
  channel: zelauction:invalidate

SQLite works out of the box. Use MySQL when several servers share one auction house, and enable Redis so listing changes show up on every server straight away.

Discord webhook

Menus and sounds

Each menu has its own file in plugins/ZelAuction/gui/ (browse, mine, collect, confirm, sell-confirm, preview, logs, admin). Sounds are set in sounds.yml.

Placeholders

Requires PlaceholderAPI. The identifier is zelauction.

PlaceholderDescription
%zelauction_listings%Active listings of the player
%zelauction_mailbox%Items waiting in the player's mailbox
%zelauction_total_listings%Active listings on the server

Recovery

If the server stops in the middle of a transfer, the operation is kept as a recovery record instead of being lost. Staff see the count in /ah-admin debug and can resolve each record with /ah-admin recovery <operation-uuid> <complete|cancel|refund>. Check the transfer first, then decide.
