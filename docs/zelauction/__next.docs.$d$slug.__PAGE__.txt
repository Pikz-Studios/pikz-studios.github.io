3:T16aa,## Overview

ZelAuction is an auction house for Paper and Folia servers. Players list items for a price, browse and search listings, buy with Vault money and collect expired or returned items from a mailbox. Search and sell prompts use native dialogs, with a chat fallback for Bedrock players.

### Requirements

* Paper or Folia 1.21.11 or newer
* Vault and a Vault-compatible economy plugin
* Optional: PlaceholderAPI, Floodgate, Geyser, ViaVersion

### Installation

1. Put `ZelAuction.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license-key` in `plugins/ZelAuction/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/ah` | Open the auction house (alias `/auction`) | `zelauction.use` |
| `/ah browse` | Browse active listings | `zelauction.use` |
| `/ah sell <price> [amount]` | Sell the item in your main hand | `zelauction.sell` |
| `/ah mine` | View your own listings (alias `items`) | `zelauction.use` |
| `/ah collect [all]` | Collect expired or returned items (aliases `mailbox`, `expired`, `claim`) | `zelauction.use` |
| `/ah search` | Search listings with a dialog | `zelauction.use` |
| `/ah transactions` | Your transaction history (alias `history`) | `zelauction.use` |
| `/ah fastbuy [on\|off]` | Skip the buy confirmation | `zelauction.fastbuy` |
| `/ah logs` | Inspect auction logs (alias `inspect`) | `zelauction.logs` |
| `/ah admin` | Open the admin menu | `zelauction.admin` |
| `/ah help` | Show the help message | `zelauction.use` |

### Admin commands

| Command | Description |
| --- | --- |
| `/ah-admin reload` | Reload all config files |
| `/ah-admin lock` | Toggle the auction house lock |
| `/ah-admin debug` | Show listing, parcel, recovery and payout counts |
| `/ah-admin recovery <operation-uuid> <complete\|cancel\|refund>` | Resolve an interrupted transfer |
| `/ah-admin force-sell <player> <price> [amount]` | Force a listing for a player |

`reload`, `lock`, `debug`, `recovery` and `force-sell` also work as `/ah <subcommand>` for staff with `zelauction.admin`.

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `zelauction.use` | Use the auction house | everyone |
| `zelauction.sell` | List items | everyone |
| `zelauction.fastbuy` | Use fast buy | everyone |
| `zelauction.logs` | View auction logs | op |
| `zelauction.admin` | All admin commands and menus | op |

### Listing limits

`Max-Item-Permissions` in `config.yml` sets how many listings a player can hold at once. The highest matching permission wins, `max-listings` is the fallback.

```yaml
max-listings: 5
Max-Item-Permissions:
  - ah.default:5
  - ah.canyon:10
  - ah.canyon+:15
  - ah.canyon++:25
```

## Configuration

### config.yml

| Option | Default | Description |
| --- | --- | --- |
| `prefix` | `&#FFD21F&lAUCTION &7▷ ` | Message prefix |
| `max-listings` | `5` | Listings per player without a limit permission |
| `confirm-sell` | `true` | Ask before listing |
| `duration-hours` | `48` | How long a listing stays up |
| `expire-check-seconds` | `30` | Interval of the expiry check |
| `expire-batch-size` | `100` | Listings processed per expiry run |
| `min-price` | `1` | Lowest allowed price |
| `max-price` | `1000000000000` | Highest allowed price |
| `tax-percent` | `5` | Tax taken from the seller on a sale |
| `listing-fee-percent` | `0` | Fee charged when listing |
| `announce-new-listings` | `false` | Broadcast new listings |
| `blacklist` | bedrock, barrier, command blocks, ... | Materials that cannot be sold |
| `block-inside-shulkers` | `true` | Also block blacklisted items inside shulker boxes |
| `logs.keep-days` | `90` | Days to keep log entries |
| `logs.max-entries` | `1000` | Maximum log entries kept |

Every permission node can be renamed under `permissions:` in `config.yml`. All messages, words, sort labels, categories and item lore live in the same file, with `&` codes and `&#RRGGBB` hex colors.

### Database

`database.yml` selects the storage backend.

```yaml
Database-Type: SQLite
MySQL:
  host: localhost
  port: 3306
  database: zelauction
  user: root
  password: ''
Redis:
  enabled: false
  host: localhost
  port: 6379
  channel: zelauction:invalidate
```

SQLite works out of the box. Use MySQL when several servers share one auction house, and enable Redis so listing changes show up on every server straight away.

### Discord webhook

`discord.yml` posts embeds to a Discord channel. It is disabled by default.

| Option | Description |
| --- | --- |
| `enabled` | Turn the webhook on |
| `webhook-url` | Your Discord webhook URL |
| `events.listed` | Post new listings |
| `events.purchased` | Post sales |
| `events.expired` | Post expired listings |
| `events.removed` | Post staff removals |

### Menus and sounds

Each menu has its own file in `plugins/ZelAuction/gui/` (`browse`, `mine`, `collect`, `confirm`, `sell-confirm`, `preview`, `logs`, `admin`). Sounds are set in `sounds.yml`.

## Placeholders

Requires PlaceholderAPI. The identifier is `zelauction`.

| Placeholder | Description |
| --- | --- |
| `%zelauction_listings%` | Active listings of the player |
| `%zelauction_mailbox%` | Items waiting in the player's mailbox |
| `%zelauction_total_listings%` | Active listings on the server |

## Recovery

If the server stops in the middle of a transfer, the operation is kept as a recovery record instead of being lost. Staff see the count in `/ah-admin debug` and can resolve each record with `/ah-admin recovery <operation-uuid> <complete|cancel|refund>`. Check the transfer first, then decide.
