3:Taeb,## Overview

Practice Setup is a full crystal PvP practice server: spawn, arenas, a desert world for random teleports, an AFK room and every plugin already configured. Players open `/menu` for the kit room, settings, shop, RTP queue, arenas, AFK room and personal vault.

### Requirements

* Paper or Purpur 1.21.8 or newer
* Java 21

## Installation

1. Download the setup from the BuiltByBit resource page.
2. Get your license key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios) and put it in `License-Key` in `plugins/Shards/config.yml`.
3. Start the server.

## Player commands

| Command | Description |
| --- | --- |
| `/menu` | The main Crystal Practice menu |
| `/kit`, `/k1` | Kit menu, or load kit 1 directly |
| `/ec1` | Load ender chest 1 |
| `/train` | Fight a netherite PvP bot with the number of totems you choose |
| `/totempractice` | Totem swap practice |
| `/rtpqueue` | Queue for a 1v1 at a random spot in the desert world |
| `/rtp` | Random teleport to the overworld or the desert world |
| `/ffa` | Crystal free-for-all arena |
| `/box` | Crystal box arena |
| `/settings` | Toggle fast crystals, scoreboard, health indicator, teleport requests and death messages |
| `/shop` | Cosmetics shop |
| `/spawn` | Back to spawn |
| `/tpa`, `/tpahere`, `/tpaccept`, `/tpatoggle` | Teleport requests |

Other commands are blocked for players by CommandWhitelist.

## Features

* **Kit room:** crystals, anchors, totems, armor, potions and every PvP item to build a kit.
* **9 kits and 9 ender chests:** right-click a slot to edit, left-click to load.
* **PvP bots and totem practice.**
* **1v1 RTP queue:** both players land at the same random spot in the desert world.
* **Arenas:** crystal FFA and the crystal box.
* **Cosmetics shop:** titles, chat colors, pets, particles, projectile trails, mounts and death effects, bought with shards.
* **Personal vault:** every cosmetic a player owns, ready to equip.
* **AFK room:** one shard every minute while standing in it.
* **Leaderboards at spawn** and NPCs that start a bot fight, join the queue or teleport you into the wilderness.

## Worlds

| World | Use |
| --- | --- |
| `Spawn` | Spawn, menus, AFK room and leaderboards |
| `arenas` | FFA and box arenas |
| `rtp` | Desert world for `/rtp`, `/rtpqueue` and bot fights |
| `world`, `world_nether` | Overworld random teleports |

## Included plugins

| Plugin | Docs |
| --- | --- |
| Shards | [Shards](/docs/shards) |

The setup also comes with Citizens, FancyNpcs, FancyHolograms, DeluxeMenus, DeluxeTags, UltraCosmetics, EssentialsX, LuckPerms, Multiverse, WorldGuard, BetterRTP, TAB, PlaceholderAPI, ViaVersion and the rest of the practice plugins, all configured.
