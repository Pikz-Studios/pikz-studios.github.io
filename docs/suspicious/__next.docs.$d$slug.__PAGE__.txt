3:Tc06,## Overview

Suspicious collects signals about each player in one place. It listens to your anticheat flags, scores suspicious mining (burst mining and ore ratios), and keeps notes and a history per player. Staff review everything in menus and get alerts in game and on Discord.

### Requirements

* Paper or Folia 1.21 or newer
* PlaceholderAPI
* Optional: GrimAC, Vulcan or Themis for anticheat flags

### Installation

1. Put `Suspicious.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license_key` in `plugins/Suspicious/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/sus` | Open the list of suspicious players | `suspicious.staff` |
| `/sus <player>` | Open a player's profile, history and notes | `suspicious.staff` |
| `/sus toggle` | Turn your own alerts on or off | `suspicious.staff` |
| `/sus anticheat [name] [on\|off]` | Open the anticheat menu or switch one anticheat | `suspicious.anticheat` |
| `/sus reload` | Reload the config | `suspicious.reload` |

## Permissions

| Permission | Description |
| --- | --- |
| `suspicious.staff` | Use `/sus`, get alerts |
| `suspicious.anticheat` | Manage anticheat sources |
| `suspicious.reload` | Reload the config |
| `suspicious.notes.delete` | Delete player notes |
| `suspicious.bypass` | Never tracked |
| `suspicious.bypass.xray` | Skipped by the mining checks |

## Configuration

| Option | Default | Description |
| --- | --- | --- |
| `database.type` | `SQLITE` | `SQLITE` or `MYSQL` |
| `anticheats.grim` / `vulcan` / `themis` | `true` | Use flags from that anticheat |
| `anticheats.minimumViolations` | `0` | Ignore flags below this violation level |
| `suspiciousFactor.alertOnlineStaff` | `true` | Alert online staff |
| `suspiciousFactor.minimumSuspiciousFlagsStaff` | `1` | Flags before staff are alerted |
| `suspiciousFactor.enableDiscordWebhookMessaging` | `false` | Send alerts to a Discord webhook |
| `suspiciousFactor.minimumSuspiciousFlagsDiscord` | `1` | Flags before Discord is alerted |
| `suspiciousFactor.alertTimeWindowSeconds` | `15` | Time window used to group alerts |
| `xrayDetection.enabled` | `true` | Enable the mining checks |
| `xrayDetection.miningDataWindowMinutes` | `20` | How long mining data is kept |
| `xrayDetection.burstMiningWindowSeconds` | `30` | Window for burst mining |
| `xrayDetection.burstMiningMinCount` | `5` | Valuable blocks in the window to flag |
| `xrayDetection.burstMiningScoreThreshold` | `40.0` | Score needed to flag a player |
| `xrayDetection.minimumTotalMinedForRatio` | `50` | Blocks mined before the ore ratio is checked |

### Categories

Flags are sorted into categories shown as menu icons: ESP, Protocol, PvP, Movement, World and Other. Each category lists the check name keywords that belong to it, so you can add your anticheat's own check names.
