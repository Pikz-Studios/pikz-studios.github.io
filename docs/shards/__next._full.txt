17:T7322,## Getting Started

Welcome to the official wiki for the Shards plugin! This guide contains everything you need to know, from initial setup and configuration to commands and developer integration.

#### Requirements

* **Minecraft Version:** 1.20+ (Recommended: 1.21+)
* **Required Plugins:** WorldGuard
* **Optional Plugins:** PlaceholderAPI, ShopGUIPlus

#### Installation

1. Download the Shards plugin
2. Place the `.jar` file in your server's `plugins` folder
3. Start/restart your server
4. Configure your `config.yml` with your license key
5. Set up your WorldGuard regions for AFK shard generation

## Commands

#### Player Commands

| Command                        | Description                   |
| ------------------------------ | ----------------------------- |
| `/<cmd> help`                  | Show help menu                |
| `/<cmd> balance`               | View your shard balance       |
| `/<cmd> pay <player> <amount>` | Send shards to another player |
| `/<cmd> shop`                  | Open the shard shop           |
| `/<cmd> leaderboard`           | View the leaderboard          |
| `/afk`                         | Teleport to AFK zone          |

#### Admin Commands

| Command                         | Permission    | Description                   |
| ------------------------------- | ------------- | ----------------------------- |
| `/<cmd> set <player> <amount>`  | `shard.admin` | Set a player's balance        |
| `/<cmd> give <player> <amount>` | `shard.admin` | Give shards to a player       |
| `/<cmd> take <player> <amount>` | `shard.admin` | Take shards from a player     |
| `/<cmd> see <player>`           | `shard.admin` | View a player's balance       |
| `/<cmd> setafk`                 | `shard.admin` | Set the AFK teleport location |
| `/<cmd> reload`                 | `shard.admin` | Reload the plugin             |

> **Note:** `<cmd>` is the command name set in `config.yml` (default: `shard`)

## Permissions

#### Basic Permissions

| Permission          | Description                           |
| ------------------- | ------------------------------------- |
| `shard.use`         | Access basic shard commands           |
| `shard.shop`        | Access the shop                       |
| `shard.pay`         | Send shards to other players          |
| `shard.leaderboard` | View the leaderboard                  |
| `shard.afk`         | Use the AFK teleport command          |
| shards.alwaysearn   | Make the player earns shards anywhere |

#### Admin Permissions

| Permission     | Description               |
| -------------- | ------------------------- |
| `shard.admin`  | Access all admin commands |
| `shard.reload` | Reload the plugin         |

#### Bonus Permissions

| Permission               | Description                 |
| ------------------------ | --------------------------- |
| `shard.gennodes.<node>`  | Bonus shards per generation |
| `shard.killnodes.<node>` | Bonus shards per kill       |

## Placeholders

**Requires** [**PlaceholderAPI**](https://www.spigotmc.org/resources/placeholderapi.6245/)

| Placeholder                       | Description                     |
| --------------------------------- | ------------------------------- |
| `%shards_value%`                  | Player's shard balance          |
| `%shards_value_formatted%`        | Formatted balance (with commas) |
| `%shards_currency%`               | Currency name                   |
| `%shards_leaderboard_<position>%` | Leaderboard entry at position   |

**Leaderboard Format (configurable in messages.yml):**

```yaml
leaderboard-placeholderapi-format: "&d%player% &7- &f%amount%"
```

## config.yml

The main configuration file for the Shards plugin.

#### License

```yaml
License-Key: "YOUR-LICENSE-KEY"
```

Get your license key from [discord.gg/pikzstudios](https://discord.gg/pikzstudios)

#### General Settings

| Option        | Type    | Default   | Description                                              |
| ------------- | ------- | --------- | -------------------------------------------------------- |
| `Currency`    | String  | `"Shard"` | The name of your currency displayed in messages          |
| `Command`     | String  | `"shard"` | Main command name (e.g., `/shard`, `/shards`, `/points`) |
| `pay-enabled` | Boolean | `true`    | Allow players to send shards to each other               |

```yaml
Currency: "Shard"
Command: "shard"
pay-enabled: true
```

#### Feature Toggles

Enable or disable specific plugin features:

```yaml
Features:
  AFK-Teleport: true    # /afk command and AFK teleportation system
  Shop: true            # In-game shop where players can spend shards
  Leaderboard: true     # Shard leaderboard GUI
```

#### Shard Generation (AFK Zones)

Configure passive shard generation in WorldGuard regions:

| Option        | Type    | Description                                       |
| ------------- | ------- | ------------------------------------------------- |
| `AFK-Regions` | List    | WorldGuard region names where players earn shards |
| `Shard-Delay` | Integer | Time in seconds between each shard generation     |

```yaml
AFK-Regions:
  - afk_zone
  - spawn_afk

Shard-Delay: 15
```

#### Generation Bonus Nodes

Grant bonus shards per generation based on permissions:

```yaml
Gen-Nodes:
  extra_two: 2      # Permission: shard.gennodes.extra_two
  extra_three: 3    # Permission: shard.gennodes.extra_three
  vip: 5            # Permission: shard.gennodes.vip
```

Players with `shard.gennodes.extra_two` will receive +2 bonus shards per generation cycle.

#### Kill Rewards

Configure shards earned from PvP kills:

| Option                     | Type    | Default | Description                                                                    |
| -------------------------- | ------- | ------- | ------------------------------------------------------------------------------ |
| `Shard-Kill`               | Integer | `15`    | Base shards awarded for killing a player                                       |
| `Kill-Nodes.prevent_abuse` | Boolean | `true`  | Prevent farming by blocking rewards for killing the same player twice in a row |

```yaml
Shard-Kill: 15

Kill-Nodes:
  prevent_abuse: true
  extra_ten: 10       # Permission: shard.killnodes.extra_ten
  extra_twenty: 20    # Permission: shard.killnodes.extra_twenty
```

#### AFK Teleport System

Configure the `/afk` teleportation command:

```yaml
AFK-Teleport:
  enable-commands: true      # Enable the /afk command
  command-name: "afk"        # Custom command name
  countdown-time: 5          # Seconds before teleporting
  use-action-bar: true       # Show countdown in action bar
  use-chat: true             # Show countdown in chat
```

#### Leaderboard Settings

```yaml
Leaderboard:
  Refresh-Rate: 1200    # Refresh interval in seconds (20 minutes)
```

> **Note:** Minimum recommended refresh rate is 300 seconds (5 minutes) to avoid performance issues.

#### Time Formatting

Customize how time is displayed in messages:

```yaml
time-format:
  labels:
    day: "d"
    hour: "h"
    minute: "m"
    second: "s"

  formats:
    '1': "%d%%day% %h%%hour% %m%%minute% %s%%second%"   # Days remaining
    '2': "%h%%hour% %m%%minute% %s%%second%"            # Hours remaining
    '3': "%m%%minute% %s%%second%"                      # Minutes remaining
    '4': "%s%%second%"                                  # Seconds only
```

#### Database Configuration

Shards supports both SQLite and MySQL:

**SQLite (Default):**

```yaml
Database:
  Type: SQLite
```

**MySQL:**

```yaml
Database:
  Type: MySQL
  MySQL:
    host: "localhost"
    port: 3306
    database: "shards"
    user: "root"
    password: "your_password"
    max-pool: 15
    use-ssl: false
    url: ""    # Leave empty to use host/port/database
```

## messages.yml

Customize all plugin messages. Supports color codes and hex colors.

#### Available Placeholders

| Placeholder  | Description                   |
| ------------ | ----------------------------- |
| `%currency%` | Currency name from config.yml |
| `%command%`  | Command name from config.yml  |
| `%player%`   | Player name                   |
| `%amount%`   | Shard amount                  |
| `%balance%`  | Player's balance              |
| `%target%`   | Target player name            |
| `%from%`     | Sender name (for payments)    |
| `%time%`     | Time remaining                |
| `%price%`    | Item price                    |
| `%missing%`  | Missing shards amount         |
| `%product%`  | Product name                  |
| `%page%`     | Current page                  |
| `%max%`      | Maximum pages                 |

#### Color Codes

* `&0-9`, `&a-f` - Standard colors
* `&l`, `&n`, `&o` - Bold, underline, italic
* `&k`, `&m` - Obfuscated, strikethrough
* `&r` - Reset
* `&#RRGGBB` - Hex colors (1.16+)

#### Example Messages

```yaml
# Shop
```

## API Overview

| -------------------- | -------------------------------------- |

| `KillMultiplayerAPI` | Kill bonus multipliers                 |

| `ShardLoseEvent`     | Event fired when a player loses shards |

## Accessing the API

Use `ShardsAPIProvider` to access the API:

```java
import bg.pikz.shards.api.ShardsAPIProvider;
import bg.pikz.shards.api.interfaces.ShardsAPI;

public class MyPlugin extends JavaPlugin {

    private ShardsAPI shardsAPI;

    @Override
    public void onEnable() {
        // Check if Shards is loaded
        if (getServer().getPluginManager().getPlugin("Shards") != null) {
            shardsAPI = ShardsAPIProvider.getAPI();
            getLogger().info("Hooked into Shards v" + shardsAPI.getVersion());
        } else {
            getLogger().warning("Shards not found! Some features will be disabled.");
        }
    }
}
```

### Modify Shard Amount Example

```java
@EventHandler
public void onShardGain(ShardGainEvent event) {
    Player player = event.getPlayer();

    // Double shards from kills for VIP players
    if (event.getReason() == ShardGainEvent.GainReason.KILL) {
        if (player.hasPermission("vip.doublekill")) {
            event.setAmount(event.getAmount() * 2);
            player.sendMessage("VIP bonus: Double kill reward!");
        }
    }

    // 50% bonus shards from AFK generation during weekend
    if (event.getReason() == ShardGainEvent.GainReason.REGION_GENERATION) {
        if (isWeekend()) {
            long bonus = event.getAmount() / 2;
            event.setAmount(event.getAmount() + bonus);
        }
    }
}
```

### Cancel Event Example

```java
@EventHandler
public void onShardGain(ShardGainEvent event) {
    Player player = event.getPlayer();

    // Disable shard gain in specific world
    if (player.getWorld().getName().equals("minigames")) {
        event.setCancelled(true);
        return;
    }

    // Prevent AFK farming during certain hours
    if (event.getReason() == ShardGainEvent.GainReason.REGION_GENERATION) {
```

### Complete Integration Example

```java
public class ShardGainListener implements Listener {

    private final MyPlugin plugin;

    public ShardGainListener(MyPlugin plugin) {
        this.plugin = plugin;
    }

    @EventHandler(priority = EventPriority.NORMAL)
    public void onShardGain(ShardGainEvent event) {
        Player player = event.getPlayer();
        long originalAmount = event.getAmount();
        ShardGainEvent.GainReason reason = event.getReason();

        // Apply multipliers based on reason
        double multiplier = getMultiplier(player, reason);
        long newAmount = (long) (originalAmount * multiplier);
        event.setAmount(newAmount);

        // Log significant gains
        if (newAmount >= 100) {
            plugin.getLogger().info(String.format(
                "%s gained %d shards (original: %d, reason: %s)",
                player.getName(), newAmount, originalAmount, reason
            ));
        }
    }

    private double getMultiplier(Player player, ShardGainEvent.GainReason reason) {
        double multiplier = 1.0;

        // Base rank multipliers
        if (player.hasPermission("rank.vip")) multiplier += 0.25;
        if (player.hasPermission("rank.mvp")) multiplier += 0.5;

        // Reason-specific multipliers
        if (reason == ShardGainEvent.GainReason.KILL) {
            if (plugin.isDoubleKillEventActive()) {
                multiplier *= 2.0;
            }
        }

        return multiplier;
    }
}
```
