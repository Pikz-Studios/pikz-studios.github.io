3:T9f9,## Overview

NeoSpawner replaces vanilla spawners with stackable spawners that fill a storage menu. Mob spawners drop loot and experience on a timer, item spawners produce items, and players collect and sell everything from the spawner menu. Boosters speed up all spawners around a player.

### Requirements

* Paper or Spigot 1.16 or newer
* Optional: Vault, PlaceholderAPI, DecentHolograms or FancyHolograms, EconomyShopGUI, Essentials, EcoBits, Towny

### Installation

1. Put `NeoSpawner.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set the license key in the config. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/neospawner reload` | Reload the config (alias `/ns`) | `neospawner.admin` |
| `/neospawner set <amount>` | Set the stack size of the spawner you are looking at | `neospawner.admin` |
| `/neospawner givems <player> <mob> <amount>` | Give mob spawners | `neospawner.admin` |
| `/neospawner giveis <player> <item> <amount>` | Give item spawners | `neospawner.admin` |
| `/neospawner givebooster` | Give a booster | `neospawner.admin` |
| `/neospawner givesellwand` | Give a sell wand | `neospawner.admin` |
| `/booster` | Booster command | `neospawner.booster` |

## Configuration

| Folder | What it holds |
| --- | --- |
| `mobSpawners/` | One file per mob such as `cow.yml` and `blaze.yml` |
| `itemSpawners/` | One file per item spawner such as `diamond.yml` |
| `boosters/` | Booster items such as `simple_booster.yml` |
| `modifiers/` | Spawner modifiers |
| `gui/` | `spawnermenu.yml`, `spawnerstorage.yml` and `corruption.yml` |

### Spawner files

| Option | Example | Description |
| --- | --- | --- |
| `profile.custom-name-for-entity` | `COW` | Name shown in menus and holograms |
| `profile.color` | `&6` | Display color |
| `settings.tick-delay` | `20-30` | Seconds between drops, as a range |
| `settings.xp-to-generate` | `15-25` | Experience per drop |
| `settings.item-content-limit` | `400` | Items the storage holds |
| `settings.xp-limit` | `2500` | Experience the storage holds |
| `settings.max-stack` | `12` | Highest stack size |
| `loots.<name>` | | Dropped items with an `amount` range |

### Boosters

A booster file sets the `name`, `time` (such as `8h`), `boost-multiplier`, the `radius` in blocks and the item players right click.
