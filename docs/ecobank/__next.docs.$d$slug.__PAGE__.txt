3:Tf00,## Overview

EcoBank adds a loan system to your server economy. Players open the bank menu, pick a loan size, and pay it back through a debt menu. Loans carry interest and a due date, and players who stay overdue run into punishments you define.

### Requirements

* Paper or Folia 1.21 or newer
* Vault and a Vault-compatible economy plugin
* Optional: PlaceholderAPI for the stat lines in menus

### Installation

1. Put `EcoBank.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license-key` in `plugins/EcoBank/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/bank` | Open the loan menu | `ecobank.bank` |
| `/debt` | Open the debt menu to repay what you owe | `ecobank.debt` |
| `/ecobank` | Open the admin config menu (aliases `/ecob`, `/eb`) | `ecobank.admin` |
| `/ecobank gui` | Open the admin config menu | `ecobank.admin` |
| `/ecobank reload` | Reload all config files | `ecobank.admin` |
| `/ecobank save` | Save the config | `ecobank.admin` |

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `ecobank.bank` | Use `/bank` | everyone |
| `ecobank.debt` | Use `/debt` | everyone |
| `ecobank.admin` | Admin command and config menu | op |

## Configuration

### config.yml

| Option | Default | Description |
| --- | --- | --- |
| `license-key` | | Your license key |
| `database.type` | `sqlite` | `sqlite` or `mysql` |
| `loans.interest-rate` | `5.0` | Interest in percent, added to every loan |
| `loans.max-active-loans` | `1` | Loans a player can hold at once |
| `loans.due-days` | `7` | Days until a loan is due |
| `loans.max-debt` | `98000.0` | Highest total debt a player can reach |
| `anti-alt.enabled` | `true` | Block loans when another online account on the same IP has an active loan |
| `punishment.check-interval-minutes` | `60` | How often overdue loans are checked |
| `stat-requirements.enabled` | `false` | Require player statistics before a loan |

### Stat requirements

When enabled, a player must meet every listed statistic before borrowing. Any Bukkit statistic name works.

```yaml
stat-requirements:
  enabled: true
  requirements:
    kills:
      statistic: PLAYER_KILLS
      min-value: 10
      display-name: Player Kills
    mob-kills:
      statistic: MOB_KILLS
      min-value: 50
      display-name: Mob Kills
```

### Loan sizes

`loans.yml` defines the loans shown in the bank menu. The defaults are `small` (1,000), `medium` (5,000), `large` (10,000) and `massive` (50,000). Each loan sets its `amount`, menu `slot`, `material`, `name` and `lore`. The lore supports `{amount}`, `{interest_rate}`, `{interest_amount}`, `{total_owed}`, `{due_days}` and `{requirements}`.

### Punishments

`punishments.yml` lists tiers that trigger when a loan is a number of days overdue. Each tier has `days-overdue`, a `type` and a `value`.

| Type | Value |
| --- | --- |
| `MESSAGE` | Message sent to the player |
| `COMMAND` | Console command, `%player%` is the player name |
| `KICK` | Kick message |
| `TEMP_BAN` | `<days>\|<reason>` |
| `BAN` | Ban reason |

```yaml
punishments:
  tier-1:
    days-overdue: 1
    type: MESSAGE
    value: '&eYour loan is overdue.'
  tier-4:
    days-overdue: 14
    type: TEMP_BAN
    value: '3|You failed to repay your loan.'
```

### Menus and messages

The bank menu and the debt menu are configured in `config.yml` under `bank-gui` and `debt-gui`: titles, sizes, filler glass, item materials, names, lore and slots. The debt menu has repay buttons for fixed amounts (`pay-amounts`) and a pay full button. All chat messages are in `messages.yml`.
