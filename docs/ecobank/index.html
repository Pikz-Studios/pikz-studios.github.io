EcoBank

A bank where players borrow money and repay it with interest.

Open

Overview

EcoBank adds a loan system to your server economy. Players open the bank menu, pick a loan size, and pay it back through a debt menu. Loans carry interest and a due date, and players who stay overdue run into punishments you define.

Requirements

  • Paper or Folia 1.21 or newer
  • Vault and a Vault-compatible economy plugin
  • Optional: PlaceholderAPI for the stat lines in menus

Installation

  1. Put EcoBank.jar in your plugins folder.
  2. Start the server once so the config files are created.
  3. Set license-key in plugins/EcoBank/config.yml. Get your key on discord.gg/pikzstudios.
  4. Restart the server.

Stat requirements

When enabled, a player must meet every listed statistic before borrowing. Any Bukkit statistic name works.

stat-requirements:
  enabled: true
  requirements:
    kills:
      statistic: PLAYER_KILLS
      min-value: 10
      display-name: Player Kills
    mob-kills:
      statistic: MOB_KILLS
      min-value: 50
      display-name: Mob Kills

Loan sizes

loans.yml defines the loans shown in the bank menu. The defaults are small (1,000), medium (5,000), large (10,000) and massive (50,000). Each loan sets its amount, menu slot, material, name and lore. The lore supports {amount}, {interest_rate}, {interest_amount}, {total_owed}, {due_days} and {requirements}.

Punishments

punishments.yml lists tiers that trigger when a loan is a number of days overdue. Each tier has days-overdue, a type and a value.

TypeValue
MESSAGEMessage sent to the player
COMMANDConsole command, %player% is the player name
KICKKick message
TEMP_BAN<days>|<reason>
BANBan reason
punishments:
  tier-1:
    days-overdue: 1
    type: MESSAGE
    value: '&eYour loan is overdue.'
  tier-4:
    days-overdue: 14
    type: TEMP_BAN
    value: '3|You failed to repay your loan.'

Menus and messages

The bank menu and the debt menu are configured in config.yml under bank-gui and debt-gui: titles, sizes, filler glass, item materials, names, lore and slots. The debt menu has repay buttons for fixed amounts (pay-amounts) and a pay full button. All chat messages are in messages.yml.
