3:Tb7a,## Overview

ModernAuction is an auction house for your server. Players list the item in their hand with `/ah sell <price>`, check it on a confirm screen, and everyone can buy it from `/ah`. Listings can be filtered by category, sorted and searched through a dialog. The plugin also includes a shard shop that admins stock in game.

### Requirements

* Paper or Folia 1.21 or newer
* Optional: PlaceholderAPI

### Installation

1. Put `DonutAuction.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license` in `plugins/DonutAuction/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/ah` | Open the auction house (aliases `/auction`, `/auctionhouse`) | `donutauction.use` |
| `/ah sell <price>` | List the item in your hand for that price | `donutauction.use` |
| `/shards give <player> <amount>` | Give shards to a player | `donutauction.admin` |
| `/shards admin` | Open the shard shop editor | `donutauction.admin` |
| `/donutauction reload` | Reload every config file (alias `/da`) | `donutauction.reload` |

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `donutauction.use` | Open the auction house and sell items | everyone |
| `donutauction.admin` | Shard admin commands and menus | op |
| `donutauction.reload` | Reload the configuration | op |

## Features

* **Auction house:** every listing shows the item, price, seller and time left.
* **Filters and sorting:** switch categories from the filter button and sort by lowest price, highest price or recently listed.
* **Search dialog:** type an item name into a dialog instead of a sign, and buy from the results with one click.
* **Confirm before listing:** `/ah sell` shows the item and price before it goes live.
* **Your Items:** see everything you have on sale and take it back at any time.
* **Shard shop:** admins add items while holding them, players buy them with shards.

## Configuration

| Option | Default | Description |
| --- | --- | --- |
| `license` | | Your license key |
| `database.type` | `SQLITE` | `SQLITE` or `MYSQL` |
| `database.host` | `127.0.0.1` | MySQL host |
| `database.port` | `3306` | MySQL port |
| `database.database` | `donutauction` | MySQL database name |
| `database.tablePrefix` | `donutauction_` | Prefix for every table |
| `database.maximumPoolSize` | `10` | Connection pool size |

Every menu has its own file: `auction-gui.yml`, `my-items-gui.yml`, `insert-item-gui.yml`, `confirm-listing-gui.yml`, `search-dialog.yml`, `sign-gui.yml`, `shard-shop-gui.yml`, `shard-confirm-gui.yml`, `shard-admin-gui.yml` and `ranks-gui.yml`. Messages are in `messages.yml` and sounds in `sounds.yml`, all with `&` and hex color codes.

## Support
