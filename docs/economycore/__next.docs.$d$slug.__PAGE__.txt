3:T3f4d,## Overview

EconomyCore (plugin name EconomySMP) is a modular core for economy SMP servers. Auctions, bounties, shards, the shop, sell menu, homes, teleports, kits, crates, duels and dozens of smaller features come in one jar. Each feature is a module that you can switch off in `config.yml`. A module that is off registers no commands.

### Requirements

* Paper or Folia 1.21 or newer
* Vault and WorldGuard
* Optional: PlaceholderAPI, ShopGUIPlus, PacketEvents (only for the hide feature)

Database libraries are downloaded by Paper on first start.

### Installation

1. Put `EconomyCore.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license-key` in `plugins/EconomySMP/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Modules

Every module has its own folder in `plugins/EconomySMP/` with a `config.yml` and often menus and messages.

| Module | What it does |
| --- | --- |
| `economy` | Balances, pay, baltop, Vault economy |
| `shop` | Category shop with fast buy and a premium shop |
| `sell` | Sell menu, worth and sell multipliers |
| `shards` | Shard currency, shop and categories |
| `auction` | Auction house with listing limits per rank |
| `order` | Buy order board for items |
| `bounty` | Player bounties |
| `coinflip` | Coinflip games with a menu |
| `invest` | Investments that pay income over time |
| `home` | Homes with a dashboard menu |
| `tpa` | Teleport requests |
| `spawn` | Spawn, first join spawn and respawn handling |
| `rtp` | Random teleport per world with a safe landing pool |
| `team` | Teams with homes and invites |
| `kits` | Kits with cooldowns and a preview menu |
| `crates` | Crates with an in game editor |
| `keyall` | Free keys for everyone on a timer |
| `ranks` | Ranks menu |
| `duel` | Duels with wagers |
| `combat` | Combat tag with blocked commands |
| `killrewards`, `playtime`, `stats`, `leaderboards` | Progress rewards, profiles and boards |
| `spawners` | Stackable spawners with loot selling |
| `vault` | Private vaults |
| `amethysttools` | Tools with amethyst effects |
| `antilag` | Timed item clear with countdown |
| `afk` | AFK area teleport |
| `autoannounce` | Rotating announcements |
| `deathmessages`, `joinmessages` | Custom death and join messages |
| `discord`, `store`, `apply`, `media` | Link, store and application messages |
| `guide`, `rules`, `settings` | Tutorial, rules and player settings menus |
| `hide`, `playerhide` | Hide yourself or other players |
| `mobtoggle`, `nightvision`, `vanilla` | Small utility commands |

## Configuration

### config.yml

| Option | Default | Description |
| --- | --- | --- |
| `license-key` | | Your license key |
| `database.type` | `sqlite` | `sqlite` or `mysql` |
| `database.table-prefix` | | Prefix for table names |
| `features.<module>` | `true` | Switch a module on or off |

### Economy

| Option | Default | Description |
| --- | --- | --- |
| `start-balance` | `10000` | Balance of new players |
| `decimals` | `2` | Decimal places |
| `max-balance` | `0` | Highest balance, `0` is unlimited |
| `currency-singular` / `currency-plural` | `Dollar` / `Dollars` | Currency names |
| `vault.register` | `true` | Register as the Vault economy |
| `format.chat` / `format.menu` | `SHORT` | Number style with K, M, B, T, Q suffixes |

### Selected module options

| Module | Option | Default | Description |
| --- | --- | --- | --- |
| `order` | `max-per-player` | `5` | Open orders per player |
| `order` | `expiry-days` | `7` | Days until an order expires |
| `order` | `min-price` / `max-price` | `1.0` / `10000000.0` | Price limits |
| `home` | `homes` / `default-homes` | `14` / `3` | Most homes and homes without a permission |
| `home` | `delay-seconds` | `5` | Teleport delay |
| `rtp` | `countdown-seconds` / `cooldown-seconds` | `5` / `10` | Countdown and cooldown |
| `rtp` | `cost` | `0` | Price of a random teleport |
| `tpa` | `expire-seconds` | `60` | Request lifetime |
| `team` | `max-members` | `30` | Members per team |
| `combat` | `duration-seconds` | `20` | Combat tag length |
| `combat` | `logout-kill` | `true` | Kill players who log out in combat |
| `coinflip` | `minimum` / `maximum` | `10` / `0` | Bet limits |
| `duel` | `expire-seconds` / `max-duration-seconds` | `60` / `900` | Request lifetime and duel length |
