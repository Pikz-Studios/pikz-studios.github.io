3:T135d,## Overview

AdminPanel puts the daily staff work into menus. Staff open a player's profile, punish from templates, manage ranks, check inventories and ender chests, freeze or vanish, restore inventories from backups and watch server performance. Actions are logged.

### Requirements

* Paper or Folia 1.16 or newer
* Optional: LuckPerms (ranks), LiteBans or AdvancedBan (punishments), GrimAC or Vulcan (anticheat), ProtocolLib, PlaceholderAPI

### Installation

1. Put `AdminPanel.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `License-Key` in `plugins/AdminPanel/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/adminpanel` | Open the admin panel (alias `/ap`) | `adminpanel.use` |
| `/adminpanel inspect <player>` | Open a player's profile | `adminpanel.inspect` |
| `/adminpanel reload` | Reload the configuration | `adminpanel.reload` |
| `/rollback list <player>` | Open a player's backup list (alias `/rb`) | `adminpanel.rollback.list` |
| `/rollback backup <player>` | Create a manual backup | `adminpanel.rollback.backup` |
| `/rollback restore <player> <id> [full\|inventory\|enderchest\|stats]` | Restore a backup | `adminpanel.rollback.restore` |
| `/staffmode` | Toggle staff mode (alias `/sm`) | `adminpanel.staffmode` |
| `/staffchat [message]` | Toggle staff chat or send one message (alias `/sc`) | `adminpanel.staffchat` |
| `/freeze <player>` | Freeze a player | `adminpanel.freeze` |
| `/unfreeze <player>` | Unfreeze a player | `adminpanel.freeze` |

## Permissions

All nodes default to op. `adminpanel.*` grants all of them.

| Permission | Description |
| --- | --- |
| `adminpanel.use` | Open the panel |
| `adminpanel.inspect` | Inspect players |

| `adminpanel.staffmode` | Staff mode |
| `adminpanel.staffchat` | Staff chat |
| `adminpanel.freeze` | Freeze and unfreeze |
| `adminpanel.rollback.use` | Use `/rollback` |
| `adminpanel.rollback.list` | List backups |
| `adminpanel.rollback.backup` | Create backups |

| `adminpanel.gui.teleport` | Teleport panel |
| `adminpanel.gui.performance` | Performance panel |
| `adminpanel.gui.activitylog` | Activity log panel |

## Configuration

### config.yml

| Option | Default | Description |
| --- | --- | --- |
| `general.locale` | `en_US` | Language file in `lang/` |
| `database.type` | `SQLITE` | `SQLITE` or `MYSQL` |
| `integrations.permissions.enabled` | `true` | Use the permissions plugin for ranks |
| `integrations.punishments.enabled` | `true` | Use LiteBans or AdvancedBan |
| `integrations.anticheat.enabled` | `true` | Read anticheat data |
| `moderation.max-warnings` | `5` | Warnings before the action below |
| `moderation.max-warnings-action` | `TEMP_BAN` | What happens at the limit |
| `moderation.max-warnings-ban-duration` | `1d` | Length of that ban |
| `moderation.broadcast-punishments` | `true` | Announce punishments |
| `inventory.snapshot-on-death` | `true` | Back up inventories on death |
| `inventory.max-snapshots` | `50` | Backups kept per player |
| `inventory.retention-days` | `30` | Days a backup is kept |
| `security.linked-accounts.max-accounts-per-ip` | `3` | Accounts per IP before an alert |
| `security.illegal-items.action` | `REMOVE` | What happens to illegal items |
| `security.anti-dupe.threshold` | `64` | Amount of a monitored item that raises an alert |
| `logging.player-activity.retention-days` | `90` | Days activity logs are kept |

### Freeze

`player-control.freeze` controls what a frozen player cannot do: chat, commands (with an allow list), movement on the Y axis, interaction, block placing and breaking. It also sets sounds, potion effects such as blindness, and `anti-disconnection`, which acts when a frozen player leaves.

### Vanish

`player-control.vanish` hides players from the tab list and can allow or block interaction and fake join and quit messages.

### Performance panel

`performance` tunes the server performance menu: sample rate, plugin and world statistics, redstone activity per chunk, entity and item counts, and a protected list of entity types that are never removed in bulk.

### Menus, templates and language

Every menu has a file in `plugins/AdminPanel/guis/`. Punishment templates for ban, IP ban, kick, mute and warn are in `templates/`. All messages are in `lang/en_US.yml`.
