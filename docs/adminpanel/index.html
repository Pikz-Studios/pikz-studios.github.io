AdminPanel

v1.0.4

Staff tools, player control, rollbacks and a server performance view in menus.

Open

Overview

AdminPanel puts the daily staff work into menus. Staff open a player's profile, punish from templates, manage ranks, check inventories and ender chests, freeze or vanish, restore inventories from backups and watch server performance. Actions are logged.

Requirements

  • Paper or Folia 1.16 or newer
  • Optional: LuckPerms (ranks), LiteBans or AdvancedBan (punishments), GrimAC or Vulcan (anticheat), ProtocolLib, PlaceholderAPI

Installation

  1. Put AdminPanel.jar in your plugins folder.
  2. Start the server once so the config files are created.
  3. Set License-Key in plugins/AdminPanel/config.yml. Get your key on discord.gg/pikzstudios.
  4. Restart the server.

Freeze

player-control.freeze controls what a frozen player cannot do: chat, commands (with an allow list), movement on the Y axis, interaction, block placing and breaking. It also sets sounds, potion effects such as blindness, and anti-disconnection, which acts when a frozen player leaves.

Vanish

player-control.vanish hides players from the tab list and can allow or block interaction and fake join and quit messages.

Performance panel

performance tunes the server performance menu: sample rate, plugin and world statistics, redstone activity per chunk, entity and item counts, and a protected list of entity types that are never removed in bulk.

Menus, templates and language

Every menu has a file in plugins/AdminPanel/guis/. Punishment templates for ban, IP ban, kick, mute and warn are in templates/. All messages are in lang/en_US.yml.
