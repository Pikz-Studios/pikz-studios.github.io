3:Tb03,## Overview

Leaderboards tracks seven stats for every player and shows them in a dialog. `/leaderboards` lists every stat, each stat opens the top 10, and clicking a player opens their profile. `/stats` opens your own profile or anyone else's.

### Requirements

* Paper or Folia 1.21.6 or newer, since the menus use native dialogs
* Optional: Vault for the money leaderboard

### Installation

1. Put `DonutLeaderboards.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `licenseKey` in `plugins/DonutLeaderboards/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios).
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/leaderboards` | Open the leaderboards dialog (alias `/lb`) | `donutleaderboards.use` |
| `/stats [player]` | Open your own profile or another player's | `donutleaderboards.use` |

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `donutleaderboards.use` | Open leaderboards and profiles | everyone |

## Tracked stats

| Stat | Key |
| --- | --- |
| Money | `money` |
| Deaths | `deaths` |
| Playtime | `playtime` |
| Blocks placed | `blocks_placed` |
| Blocks broken | `blocks_broken` |
| Mobs killed | `mobs_killed` |
| Money earned with `/sell` | `sell_earned` |

Names, icons and number formats of every stat are set in `stats.yml`.

## Features

* **Leaderboards dialog:** every stat one click away.
* **Top 10:** each stat shows the top players with their heads and values.
* **Player profiles:** click a player on a leaderboard to see all of their stats.
* **Full profile:** View Full Profile opens a menu with every stat as its own item.

## Configuration

`config.yml`

| Option | Default | Description |
| --- | --- | --- |
| `licenseKey` | | Your license key |
| `usePermission` | `donutleaderboards.use` | Permission needed to open the menus |
| `leaderboardLimit` | `10` | Players shown per leaderboard |
| `cacheSeconds` | `60` | How often leaderboards refresh |
| `playtimeFlushSeconds` | `60` | How often playtime is saved |
| `sellCommandPrefixes` | `/sell` | Commands that count toward `sell_earned` |
| `sellBalanceCheckDelayTicks` | `5` | Delay before the balance change of a sell is read |

`database.yml`

| Option | Default | Description |
| --- | --- | --- |
| `type` | `SQLITE` | `SQLITE` or `MYSQL` |
| `sqliteFile` | `leaderboards.db` | SQLite file name |
| `host` | `127.0.0.1` | MySQL host |
| `database` | `donutleaderboards` | MySQL database name |
| `tablePrefix` | `donutlb_` | Prefix for every table |

The dialogs are in `dialogs.yml`, the full profile menu in `gui.yml` and every message in `messages.yml`.

## Support
