17:Tf4f,## Overview

Boosters is an all-in-one booster plugin. Players own boosters, open `/booster` and activate them from a menu. A booster can multiply XP, money and drops, give a potion style effect, protect the inventory or track a stat. Active boosters show on a boss bar, and global boosters are announced to the whole server.

### Requirements

* Paper or Folia 1.21 or newer
* Optional: PlaceholderAPI, LuckPerms, Vault

### Installation

1. Put `Boosters.jar` in your `plugins` folder.
2. Start the server once so the config files are created.
3. Set `license-key` in `plugins/Boosters/config.yml`. Get your key on [discord.gg/pikzstudios](https://discord.gg/pikzstudios). The plugin does not start without a valid key.
4. Restart the server.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/booster` | Open the booster menu (aliases `/boosters`, `/boost`) | `boosters.use` |

Admins use the same command to give boosters, start global boosters, list and remove them, and reload the config. The plugin replies with the exact usage when the arguments are wrong.

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `boosters.use` | Open the menu and activate owned boosters | everyone |
| `boosters.admin` | Give, remove and manage boosters | op |

## Configuration

### config.yml

| Option | Default | Description |
| --- | --- | --- |
| `license-key` | | Your license key |
| `config-reload-check-ms` | `1000` | How often file changes are checked |
| `storage.save-interval-seconds` | `300` | Autosave interval |
| `stacking.mode` | `MULTIPLY` | How several active boosters combine |
| `stacking.max-multiplier` | `10.0` | Highest combined multiplier |
| `bossbar.enabled` | `true` | Show active boosters on a boss bar |
| `bossbar.color` | `YELLOW` | Boss bar color |
| `bossbar.title` | | Boss bar text, supports `%display%` and `%time%` |
| `notifications.join-active` | `true` | Tell joining players about active boosters |
| `notifications.broadcast-global` | `true` | Announce global boosters |
| `thank.enabled` | `true` | Let players thank a booster owner |
| `thank.cooldown-seconds` | `300` | Time between thanks |
| `thank.reward` | `[]` | Commands run as a thank reward |

### Booster categories

Boosters live in six files in `plugins/Boosters/boosters/`. Every booster has an `enabled` flag, a `display` name, a `multiplier`, a `duration` (`30m`, `1h`), a `scope`, the `effects` it applies, and its menu `slot` and `item`.

| File | What it holds |
| --- | --- |
| `earnings.yml` | XP, mob loot, ore, fishing, money and luck boosters |
| `special.yml` | Combined boosters such as god, miner, mega, keys and hunter |
| `abilities.yml` | Speed, haste, jump, strength, fly, night vision, dolphin's grace, slow falling, invisibility, conduit, hero and no fall |
| `survival.yml` | Regeneration, resistance, fire resistance, water breathing, absorption, saturation, keep inventory and health boost |
| `curses.yml` | Slowness, weakness, mining fatigue, blindness, poison, hunger, levitation, glowing, darkness, unluck, nausea and wither |
| `stats.yml` | Double kills, double deaths and boosters that track mobs killed, blocks broken, blocks placed, playtime, fish caught and damage dealt |

The `effects` list takes values such as `XP`, `MONEY`, `MOB_DROPS`, `BLOCK_DROPS`, `KEEP_INVENTORY`, `FLY` and any potion effect name.

```yaml
boosters:
  xp:
    enabled: true
    display: "&a2x XP"
    multiplier: 2.0
    duration: 30m
    scope: PERSONAL
    effects: [XP]
    slot: 10
```

### Menus and messages

`menus.yml` controls the main menu, category menus and the active boosters menu. `messages.yml` holds every chat message with `&` and `#RRGGBB` colors, and the prefix. Sounds for open, activate, end, error and thank are set in `config.yml`.
